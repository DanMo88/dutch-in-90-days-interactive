# Dutch in 90 Days — Interactive Course (Days 1–90)

Interactive phone course for Persian speakers learning Dutch, based on the book *Dutch in 90 Days* by Daniel Mozafari.

Live: https://danmo88.github.io/dutch-in-90-days-interactive/

All 90 days (A1 → B1), one lesson per day. Each day: story with audio + transcript (sentence highlight, slow/normal speed) → comprehension quiz → key words (de/het colour-coded; intro + quiz) → sentence building → review & corrections.
Installable PWA, works offline, progress saved on the device.

Audio companion: https://danmo88.github.io/dutch-in-90-days/

Per day: the book's story audio and illustration, word-timed highlighting, the book's comprehension questions, 15–20 key words (incl. the book's word list), 5 sentence-building items.
