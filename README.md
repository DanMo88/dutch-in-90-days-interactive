# Dutch in 90 Days — Interactive Course (Day 1 sample)

Interactive phone course for Persian speakers learning Dutch, based on the book *Dutch in 90 Days* by Daniel Mozafari.

Live: https://danmo88.github.io/dutch-in-90-days-interactive/

Each day: story with audio + transcript (sentence highlight, slow/normal speed) → comprehension quiz → key words (de/het colour-coded; intro + quiz) → sentence building → review & corrections.
Installable PWA, works offline, progress saved on the device.

Audio companion: https://danmo88.github.io/dutch-in-90-days/
